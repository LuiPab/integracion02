1.- Eres el encargado de diseñar una estructura XML para administrar una libreria en linea.

2.- Crea un archivo XML dentro de /apps/services/soap/library.xml que contenga una lista de libros obtenidos de la base de datos de postgres de acuerdo al esquema disponible en /apps/library/db/schema.sql y con los datos ya integrados del mismo

3.- El XML debe contener una estructura orientada a libros con ISBN, titulo, autor, año de publicacion, genero, precio, stock, formato, imagenes y conceptos definidos por libros.

4.- El diseño debe de estar en idioma ingles.
